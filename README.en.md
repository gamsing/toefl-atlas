# TOEFL Atlas · 托词

Illustrated TOEFL vocabulary, forked from [Word Atlas（词光）](https://github.com/designfuchen/word-atlas).

**Not an official ETS or TOEFL product.** TOEFL is a trademark of Educational Testing Service. This project is not affiliated with ETS and does not promise a score.

4,429 academic and campus lemmas, each with an illustration, US and UK pronunciation, and a spoken first example. FSRS review. Chinese guide: [README.md](README.md).

```bash
npm ci
npm run dev
```

Open http://localhost:5471.

`npm test` · `npm run check:atlas` · `npm run build`
